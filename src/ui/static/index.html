Agent setup commands

An agent can run this itself. It initializes the ledger, writes the mode, wires the detected harness and writes AGENTS.md.

npx attesso connect --write --mode observe

Inspect the machine-readable result without a dashboard:

npx attesso status --json

For a custom harness, send one proposed tool call as JSON on stdin and read the verdict on stdout:

npx attesso hook --observe

Use npx attesso mode enforce when the observe pass looks right.
